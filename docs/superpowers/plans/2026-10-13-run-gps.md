# Run GPS Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** While a run is active the phone records GPS fixes; the Done screen and the logbook Run tab show distance, top speed, average speed and vertical drop.

**Architecture:** A pure `RunTrack` object turns fixes into a `TrackSummary` and a displayable `TrackReport`. `RunController` gets a `RunLocation` seam (like `RunBoots` and `RunSink`) and forwards fixes to the sink while RUNNING. The service owns a platform `GpsListener`, promotes itself to the `location` foreground type only while tracking, and writes fixes to a new `run_track` table (database version 10). The UI adds a GPS row and switch on the Ready screen and one card on Done and in the logbook.

**Tech Stack:** Kotlin, platform `LocationManager` (no Play services), SQLite via `LocalSessionStore`, JUnit4 on the JVM, the custom `StorageInstrumentation` runner on the emulator.

**Spec:** `docs/superpowers/specs/2026-10-12-run-gps-design.md`

## Global Constraints

- No new dependencies; platform APIs only (CLAUDE.md: "no Compose/AndroidX deps beyond the platform").
- minSdk 26, compile/target SDK 36; Java 17 source compat.
- GPS is used for **runs only**; never for test recordings, drills or plain sessions.
- Demo runs never have GPS and are labelled so.
- Track stays on the phone: **no** CSV or ZIP export of it; `SessionExport` is not touched.
- Accuracy filter 25 m, jump filter 40 m/s, top speed held 2 s, vertical drop needs 10 or more fixes with vertical accuracy (spec "How it works").
- Wording: "Phone GPS readings, not a measure of technique." Scores and coaching claims stay dry-ski only.
- UI uses `Snow`, not `SkiUi`, for new training screens (CLAUDE.md).
- Database changes need a migration plus an instrumentation check (CLAUDE.md).
- Edits to files with CRLF endings must keep CRLF (check with `file <path>`; this repo has mixed endings).

## Review Focus

- A fix whose phone reports no accuracy must be dropped, never treated as perfect (Task 1).
- Duplicate or backwards timestamps must be dropped without exceptions or divide-by-zero (Task 1).
- A run with zero, one or two usable fixes must not crash or show NaN, and says "No GPS fix" or shows partial rows (Task 1).
- Permission refused, or the location provider off at start: the run still starts, records no track, and says so (Tasks 3, 4).
- Revoked permission or a thrown `SecurityException` mid-run must not kill the service or the run; `stop()` is safe to call twice (Task 4).

```kotlin
package com.openski.android

import java.util.Locale
import kotlin.math.asin
import kotlin.math.cos
import kotlin.math.max
import kotlin.math.min
import kotlin.math.pow
import kotlin.math.roundToInt
import kotlin.math.sin
import kotlin.math.sqrt

/** One phone location reading. Altitude, speed and vertical accuracy are null when the phone did not report them. */
data class GpsFix(
    val timeMs: Long, val lat: Double, val lon: Double, val altM: Double?, val speedMps: Double?,
    val accuracyM: Float, val verticalAccuracyM: Float?,
)

data class TrackSummary(
    val distanceM: Double, val topSpeedMps: Double?, val avgSpeedMps: Double?, val movingSeconds: Int,
    val verticalDropM: Double?, val usableFixes: Int, val totalFixes: Int,
)

/** What a card shows: a headline, label/value rows (empty when there is nothing to show) and a closing note. */
data class TrackReport(val headline: String, val rows: List<Pair<String, String>>, val note: String)

/** Phone GPS readings turned into run numbers. Dry-ski boot data and technique claims live elsewhere. */
object RunTrack {
    const val MAX_ACCURACY_M = 25f
    const val MAX_JUMP_MPS = 40.0
    const val MAX_GAP_MS = 10_000L
    const val MOVING_MPS = 0.5
    const val TOP_SPEED_HOLD_MS = 2_000L
    const val MIN_ALTITUDE_FIXES = 10
    const val NOTE = "Phone GPS readings, not a measure of technique."
    private const val CONSECUTIVE_MS = 3_000L
    private const val SMOOTH_WIDTH = 5
    private const val EARTH_M = 6_371_000.0

    /** A reading whose phone reported no accuracy is given a hopeless one so the filter drops it. */
    fun fixFrom(timeMs: Long, lat: Double, lon: Double, altM: Double?, speedMps: Float?, accuracyM: Float?,
                verticalAccuracyM: Float?, nowMs: Long) = GpsFix(
        if (timeMs > 0) timeMs else nowMs, lat, lon, altM, speedMps?.toDouble(), accuracyM ?: 999f, verticalAccuracyM)

    private fun distanceM(a: GpsFix, b: GpsFix): Double {
        val p1 = Math.toRadians(a.lat); val p2 = Math.toRadians(b.lat)
        val h = sin((p2 - p1) / 2).pow(2) + cos(p1) * cos(p2) * sin(Math.toRadians(b.lon - a.lon) / 2).pow(2)
        return 2 * EARTH_M * asin(min(1.0, sqrt(h)))
    }

    /** Readings in time order, without poor accuracy, repeated or backwards times, or impossible jumps. */
    fun usable(fixes: List<GpsFix>): List<GpsFix> {
        val kept = ArrayList<GpsFix>()
        for (fix in fixes.sortedBy { it.timeMs }) {
            if (!fix.lat.isFinite() || !fix.lon.isFinite() || fix.accuracyM > MAX_ACCURACY_M) continue
            val previous = kept.lastOrNull()
            if (previous != null) {
                val dtMs = fix.timeMs - previous.timeMs
                if (dtMs <= 0) continue
                if (dtMs <= MAX_GAP_MS && distanceM(previous, fix) / (dtMs / 1000.0) > MAX_JUMP_MPS) continue
            }
            kept.add(fix)
        }
        return kept
    }

    private fun speeds(kept: List<GpsFix>): DoubleArray = DoubleArray(kept.size) { i ->
        val reported = kept[i].speedMps
        when {
            reported != null && reported >= 0 -> reported
            i == 0 -> 0.0
            else -> {
                val dtMs = kept[i].timeMs - kept[i - 1].timeMs
                if (dtMs in 1..MAX_GAP_MS) distanceM(kept[i - 1], kept[i]) / (dtMs / 1000.0) else 0.0
            }
        }
    }

    fun summarize(fixes: List<GpsFix>): TrackSummary {
        val kept = usable(fixes)
        val speed = speeds(kept)
        var distance = 0.0
        var movingMs = 0L
        for (i in 1 until kept.size) {
            val dtMs = kept[i].timeMs - kept[i - 1].timeMs
            if (dtMs > MAX_GAP_MS || speed[i] < MOVING_MPS) continue
            distance += distanceM(kept[i - 1], kept[i])
            movingMs += dtMs
        }
        return TrackSummary(
            distance, topSpeed(kept, speed),
            if (movingMs > 0) distance / (movingMs / 1000.0) else null,
            (movingMs / 1000.0).roundToInt(), verticalDrop(kept), kept.size, fixes.size)
    }

    /** The highest speed that stayed at or above that value for [TOP_SPEED_HOLD_MS], so one noisy fix cannot set it. */
    private fun topSpeed(kept: List<GpsFix>, speed: DoubleArray): Double? {
        var best: Double? = null
        for (i in kept.indices) {
            var low = speed[i]
            var j = i
            var broken = false
            while (kept[j].timeMs - kept[i].timeMs < TOP_SPEED_HOLD_MS) {
                if (j + 1 >= kept.size || kept[j + 1].timeMs - kept[j].timeMs > CONSECUTIVE_MS) { broken = true; break }
                j++
                low = min(low, speed[j])
            }
            if (!broken && (best == null || low > best)) best = low
        }
        return best
    }

    private fun verticalDrop(kept: List<GpsFix>): Double? {
        val altitudes = kept.filter { it.altM != null && it.verticalAccuracyM != null }.map { it.altM!! }
        if (altitudes.size < MIN_ALTITUDE_FIXES) return null
        val smooth = altitudes.indices.map { i ->
            altitudes.subList(max(0, i - SMOOTH_WIDTH / 2), min(altitudes.size, i + SMOOTH_WIDTH / 2 + 1)).average()
        }
        return max(0.0, smooth.first() - smooth.min())
    }

    private fun distanceText(m: Double) = if (m < 1000) "${m.roundToInt()} m" else String.format(Locale.US, "%.2f km", m / 1000)
    private fun speedText(mps: Double?) = if (mps == null) "not available" else "${(mps * 3.6).roundToInt()} km/h"

    fun report(demo: Boolean, gpsOn: Boolean, summary: TrackSummary?): TrackReport = when {
        demo -> TrackReport("No GPS in demo runs", emptyList(), NOTE)
        !gpsOn -> TrackReport("GPS was off for this run", emptyList(), NOTE)
        summary == null || summary.usableFixes == 0 -> TrackReport("No GPS fix during this run", emptyList(), NOTE)
        else -> TrackReport("On the hill", listOf(
            "Distance" to distanceText(summary.distanceM),
            "Top speed" to speedText(summary.topSpeedMps),
            "Average speed" to speedText(summary.avgSpeedMps),
            "Vertical drop" to (summary.verticalDropM?.let { "${it.roundToInt()} m" } ?: "not available"),
            "Fixes" to "${summary.usableFixes} of ${summary.totalFixes} usable",
        ), NOTE)
    }
}
```

package com.openski.android

import android.content.Context
import kotlin.math.roundToInt

enum class GpsState { OFF, NO_PERMISSION, LOCATION_OFF, WAITING, READY }

data class GpsStatus(val state: GpsState, val accuracyM: Int? = null) {
    fun label(): String = when (state) {
        GpsState.OFF -> "GPS off"
        GpsState.NO_PERMISSION -> "GPS needs location permission"
        GpsState.LOCATION_OFF -> "Location is off on this phone"
        GpsState.WAITING -> "GPS · waiting for signal"
        GpsState.READY -> "GPS ready · accuracy ${accuracyM ?: "?"} m"
    }
}

/** What the Ready screen's GPS row says. Never blocks a run: every state still allows starting. */
object GpsStatusRule {
    const val FRESH_MS = 10_000L

    fun decide(enabled: Boolean, permitted: Boolean, providerOn: Boolean, lastFixAgeMs: Long?, accuracyM: Float?): GpsStatus = when {
        !enabled -> GpsStatus(GpsState.OFF)
        !permitted -> GpsStatus(GpsState.NO_PERMISSION)
        !providerOn -> GpsStatus(GpsState.LOCATION_OFF)
        lastFixAgeMs == null || accuracyM == null || lastFixAgeMs > FRESH_MS || accuracyM > RunTrack.MAX_ACCURACY_M ->
            GpsStatus(GpsState.WAITING)
        else -> GpsStatus(GpsState.READY, accuracyM.roundToInt())
    }
}

        get() = prefs.getBoolean("enabled", true)

    var asked: Boolean
        get() = prefs.getBoolean("asked", false)

}

package com.openski.android

import android.Manifest
import android.annotation.SuppressLint
import android.content.Context
import android.content.pm.PackageManager
import android.location.Location
import android.location.LocationListener
import android.location.LocationManager
import android.os.Looper

/** One-second GPS updates from the platform `LocationManager`, delivered on the main thread. */
class GpsListener(private val context: Context, private val onFix: (GpsFix) -> Unit) {
    private val manager = context.getSystemService(LocationManager::class.java)
    private var active = false
    private val listener = object : LocationListener {
        override fun onLocationChanged(location: Location) {
            onFix(RunTrack.fixFrom(
                location.time, location.latitude, location.longitude,
                if (location.hasAltitude()) location.altitude else null,
                if (location.hasSpeed()) location.speed else null,
                if (location.hasAccuracy()) location.accuracy else null,
                if (location.hasVerticalAccuracy()) location.verticalAccuracyMeters else null,
                System.currentTimeMillis()))
        }
    }

    val permitted: Boolean
        get() = context.checkSelfPermission(Manifest.permission.ACCESS_FINE_LOCATION) == PackageManager.PERMISSION_GRANTED
    val providerOn: Boolean
        get() = try { manager.isProviderEnabled(LocationManager.GPS_PROVIDER) } catch (_: Exception) { false }

    /** False when it cannot start (no permission, location off, or the platform refused). */
    @SuppressLint("MissingPermission")
    fun start(): Boolean {
        if (active) return true
        if (!permitted || !providerOn) return false
        return try {
            manager.requestLocationUpdates(LocationManager.GPS_PROVIDER, 1000L, 0f, listener, Looper.getMainLooper())
            active = true
            true
        } catch (_: SecurityException) { false }
    }

    fun stop() {
        if (!active) return
        active = false
        try { manager.removeUpdates(listener) } catch (_: Exception) { /* permission revoked or provider gone: nothing to remove */ }
    }
}
