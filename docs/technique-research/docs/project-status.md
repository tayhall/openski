# Delivery status

This is an ongoing research project, not a completed validated coaching system.

| Deliverable | Current state | Work still required |
|---|---|---|
| A. Knowledge base | Initial structured concepts and hypotheses with source IDs | Broader appraisal, coach review, contradictions and task-specific outcomes |
| B. Video pipeline | Executable local pose extraction and reviewed-turn summaries; software checks passed | Skiing footage evaluation, robust quality review and phase-candidate experiments |
| C. Reference dataset | Schemas and unmeasured examples only | Multiple permitted recordings, annotation, analysis and contextual distributions |
| D. Sensor mapping | Proposed capability and acquisition specification | Exact algorithm replication and synchronised hardware validation |
| E. Scoring recommendations | Candidate descriptive metrics and evidence gates | Outcome validation before performance scores or prescriptive feedback |
| F. Developer integration | Draft turn contract, CLI, methods and documentation | Versioned sensor contracts, metric registry and validated integration fixtures |

The catalogue contains 50 resources: 20 technical/discovery sources and 30 individually identified YouTube videos. There are 33 qualitative findings, separate viewing provenance and a coverage audit. Selected playback frames were inspected for 29 videos; V03 has preview/description review only. No video is claimed as a complete lesson review, and no numerical reference measurements were produced. Source permissions remain unknown unless explicitly recorded otherwise.

A [repository handoff](openski-handoff.md) and [candidate metric registry](../integration/metric-registry.json) specify what the main OpenSki project can use now: acquisition requirements, descriptive feature definitions and validation work. They contain no validated technique thresholds or performance scores.

Revision 2 adds [17 provisional parameter entries](../integration/provisional-parameters.json), eight [manual projected-image proxies](../research/provisional-video-estimates.json) from three annotated frames, and their [interpretation](provisional-interpretation.md). These numerical examples are not anatomical measurements or population reference ranges. The original 33 qualitative findings remain separate and unchanged.

Qualitative study of publicly viewable YouTube demonstrations can proceed now and does not depend on user-provided footage. Selected previews and playback excerpts have been visually inspected; see the YouTube viewing notes for exact coverage and limits. Numerical reference datasets still require appropriate processing rights and suitable recordings. Sensor-transfer validation additionally requires raw IMU recordings synchronised with the same skier on video. These requirements must not be used to block the public-video conceptual research.
